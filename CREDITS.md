# Credits

## Original game content

Everything in this game was created for BLOCK MAYHEM: THE SPICE PROTOCOL:

- **Code:** all game logic (`core/`), presentation (`src/`), tools (`tools/`) and tests (`tests/`).
- **Graphics:** generated by `tools/gen_graphics.py` from original pixel-art designs in code
  (fonts, block tiles, special-cell symbols, frames, panels, effects, icons, backgrounds).
  No third-party sprites, tiles or fonts are used.
- **Music:** 14 original compositions (+8 arrangements) written in `tools/audio/songs.py` and rendered
  to XM modules by `tools/audio/composer.py`; instruments are synthesized waveforms.
- **Sound effects:** 44 effects synthesized by `tools/audio/sfx.py` (oscillators, noise, envelopes).

No copyrighted graphics, music, samples, logos or characters from other games are included.
